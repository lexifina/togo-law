# Article 3
Peuvent bénéficier du régime de droit commun sur le territoire de la République Togolaise les catégories d'entreprises suivantes :
1 — les entreprises d'exploitations rurales ; 2 — les entreprises industrielles ; 3 — les entreprises artisanales ; 4 — les entreprises d'aménagements touristiques ; 5 — les entreprises de transport.
