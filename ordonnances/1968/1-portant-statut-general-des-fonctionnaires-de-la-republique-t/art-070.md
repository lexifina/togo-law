# Article 70
Sont considérées comme positions normales d'activité, les situations suivantes : 1) — le congé administratif ; 2) — le congé de longue durée ; 3) — le congé de convalescence ou de cure thermale ; 4) — le maintien par ordre sans affectation ; 5) — le stage de formation professionnelle ; 6) — le congé pour affaires personnelles ; 7) — le congé pour examen ; 8) — le congé de maternité ; 9) — les autorisations spéciales d'absence.
