# Article 96
Les embellissements qui font l'objet d'aménagements paysagers regroupent :
- les espaces verts ; - les plantations d'alignement ; - les jardins ; - les ceintures vertes ; - les parterres ; - les parcs urbains ; - les squares ; - les monuments ; - les embellissements des sites, des monuments et des voies publiques.
