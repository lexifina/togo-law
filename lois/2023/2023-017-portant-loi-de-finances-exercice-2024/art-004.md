# Article 4
Recettes budgétaires et ressources de trésorerie
Les recettes budgétaires sont composées de :
- recettes fiscales : 1.042.112.820.000 FCFA ;
- recettes non fiscales : 61.977.344.000 FCFA ;
- dons-programmes : 12.791.000.000 FCFA ;
- dons-projets : 162.185.056.000 FCFA.
Les ressources de trésorerie sont constituées de :
- titres publics : 607.960.250.000 FCFA ;
- emprunts projets : 140.680.457.000 FCFA ;
- autres emprunts : 147.220.000.000 FCFA.
