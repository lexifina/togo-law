# Article 4
Recettes budgétaires et ressources de trésorerie
Les recettes budgétaires sont composées de : - recettes fiscales : 912.097.382.000 FCFA ; - recettes non fiscales : 60.067.946.000 FCFA ; - appuis budgétaires : 19.371.000.000 FCFA ; - dons-projets : 212.566.906.000 FCFA.
Les ressources de trésorerie sont constituées de :
- titres publics : 506.390.436.000 FCFA ; - emprunts projets : 128.604.710.000 FCFA ; - autres emprunts : 132.000.000.000 FCFA.
