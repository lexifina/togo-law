# Article 4
Recettes budgétaires et ressources de trésorerie
Les recettes budgétaires sont composées de :
- recettes fiscales : 1.113.371.327.000 FCFA ; - recettes non fiscales : 72.147.344.000 FCFA ; - appuis budgétaires : 16.791.188.000 FCFA ; - dons-projets : 141.189.391.000 FCFA.
Les ressources de trésorerie sont constituées de :
- titres publics : 450.723.277.000 FCFA ; - emprunts projets : 157.837.279.000 FCFA ; - autres emprunts : 292.679.648.000 FCFA.
