# Article 1
Des communes urbaines sont créées dans les chefs-lieux des préfectures ci-après et reçoivent les dénominations suivantes :
- Commune urbaine de Kévé dans la préfecture de l'Avé ; - Commune urbaine de Danyi-Apéyémé dans la préfecture de Danyi ; - Commune urbaine d'Agou-Gadzépé dans la préfecture d'Agou ;
- Commune urbaine de Blitta dans la préfecture de Blitta ; - Commune urbaine d'Elavagnon dans la préfecture de l'Est-Mono ; - Commune urbaine de Tohoun dans la préfecture du Moyen-Mono ; - Commune urbaine de Tandjoaré dans la préfecture de Tandjoaré ; - Commune urbaine de Mandouri dans la préfecture de Kpendjal ; - Commune urbaine de Guérin-Kouka dans la préfecture de Dankpen.
