# Article 150
Pour le calcul de l'impôt, toute fraction du bénéfice imposable inférieure à 1.000 francs est négligée.
Les taux de l'impôt sur les sociétés sont fixés à :
- Abrogé ;
- 27 % du bénéfice imposable pour les industries ;
- 30 % du bénéfice imposable pour les autres.
(suite abrogée)
