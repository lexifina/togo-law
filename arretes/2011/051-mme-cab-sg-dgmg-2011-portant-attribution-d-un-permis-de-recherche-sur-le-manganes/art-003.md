# Article 3
Les sommets de ce périmètre devront être matérialisés sur le sol par des bornes en maçonnerie portant les inscriptions suivantes :
SGM-BORC ; SGM-BORD ; SGM-BORE ; SGM-BORF ; SGM-BORM ; SGM-BORN ; SGM-BORO ; SGM-BORQ.
La signification des inscriptions SGM, BOR et (C, D, E, F, M, N, O, Q) est la suivante :
SGM : «Société Générale des Mines SARL» ; BOR : Borgou et (C, D, E, F, M, N, O, Q) : sommets du périmètre ainsi délimité.
