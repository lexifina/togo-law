# Article 5
Après une année d'assurance sans sinistre, la majoration de 20 % de la prime de référence est supprimée et les majorations supérieures sont modifiées suivant le tableau n° 3 ci-après.
Tableau 3 :
ANNEE SANS SINISTRE
| Année d'Assurance considérée | Année précédente | | Nouveaux taux de Malus applicables | | --- | --- | --- | --- | | | Nombre de sinistres | Taux de Malus appliqués | | | Sans sinistre après des années de Malus | 1 sinistre | 20 % | 0 % | | | 2 sinistres | 40 % | 20 % | | | 3 sinistres | 60 % | 40 % | | | 4 sinistres | 100 % | 60 % |
