# Article 1
— A partir du 1er avril 1945 les poids nets des sacs de produits du cru du Togo destinés à l'exportation sont fixés comme suit :
| PRODUITS | POIDS NET PAR SAC | | --- | --- | | Cacao | 70 | | Palmistes | 80 | | Arachides décortiquées | 75 | | Coprah | 60 | | Ricin | 60 | | Caoutchouc | 50 | | Tapioca | 70 | | Graines de colon | 50 | | Maïs | 90 | | Amandes de karité | 75 | | Café | 70 | | Piments | 40 |
