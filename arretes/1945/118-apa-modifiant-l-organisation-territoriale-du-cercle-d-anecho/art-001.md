# Article 1
— Le cercle d'Anécho est constitué par les cantons suivants :
JOURNAL OFFICIEL DU TERRITOIRE DU TOGO
1° — Canton de Glidji — chef-lieu Glidji, comprenant les villages de Glidji — Glidji Kpodji — Assoukopé — Zalivé — Zoolagan — Zoola Kpoguédé — Anfouin — Hounlokoué — Afdégnigban — Atouèta — Agouègan — Agnronkopé — Djankassè — Kouénou — Akoda — Agbantokopé — Badougbé Kéta — Badougbé Adjomé — Djéta — Sèko.
2° — Canton d'Aklakou — chef-lieu Aklakougan, comprenant les villages d'Aklakougan — Aklakou Molokou — Aklakou Etchavi — Kpondavé — Avévé — Adamé — Agbanakin — Sivamé — Azimé — Hlandé.
3° — Canton d'Attitogon — chef-lieu Attitogon, comprenant les villages d'Attitogon — Attivé Attitogon — Hompou — Agbétiko — Agomé-Séva — Batonou — Zooti — Tanou.
4° — Canton des Afagnans — chef-lieu Afagnan Bléta Maoussi, comprenant les villages d'Afagnan — Afagnan Bléta Atchadomé — Afagnan Bléta Maoussi — Afagnan Bléta Kpétémé.
5° — Canton d'Agomé-Glozou — chef-lieu Agomé-Glozou, comprenant les villages d'Agomé-Glozou — Alouènou — Akladjénou — Tokpli — Sikakondji.
6° — Canton de Tabligbo — chef-lieu Tabligbo, comprenant les villages de Tabligbo — Sikpé Adégoun — Essè Godjin — Essè Ana — Lakatakondji — Sikpé Afidégnon — Tométikondji — Djrékpon — Gboto Vodougbé — Gboto Eklohomé — Gboto Sévé — Kouvé Atchavé — Kouvé Atran — Kouvé Gboli — Kouvé Dafor — Safi Etchrami — Safi Etchavi — Safi Kpondavé — Safi Dokor — Essè Zogbédji — Essè Nadjé — Tchekpo Dédékoè — Tchékpo Dévé — Tchékpo Anagali — Ahoutékondji — Ahépé Akposso — Ahépé Assiko — Ahépé Kpowla — Ahépé Nuatché.
7° — Canton d'Amégnran — chef-lieu Amégnran, comprenant les villages de Amégnran — Momé Gbavé — Momé Hounkpati.
8° — Canton de Vokoutimé — chef-lieu Vokoutimé, comprenant les villages de Vokoutimé — Vo Tokpli — Kponou — Klologo.
9° — Canton de Vogan — chef-lieu Vogan, comprenant les villages de Vogan Pédakondji — Afouimé — Vo Attivé — Vo Asso — Dagbati — Akoumapé Assiko — Akoumapé Doulasssa — Akoumapé Atchavé — Hahotoé — Sévagan — Wogba — Vo Davou.
10° — Canton de Porto-Seguro — chef-lieu Porto-Seguro, comprenant les villages de Porto-Seguro — Sewatchikopé — Gounkopé — Batékopé — Togokomé — Gbodjomé — Ekpoui.
