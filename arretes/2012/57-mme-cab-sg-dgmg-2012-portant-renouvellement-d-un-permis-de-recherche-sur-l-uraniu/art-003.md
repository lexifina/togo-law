# Article 3
Les sommets de ce périmètre seront matérialisés sur le sol par des bornes en maçonnerie portant les inscriptions suivantes :
SGB-KPTA ; SGB-KPTB ; SGB-KPTC ; SGB-KPTD ; SGB-KPTE ; SGB-KPTF ; SGB-KPTG ; SGB-KPTH ; SGB-KPTI ;
Les inscriptions SGB, KPT et (A, B, C, D, E, F, G, H, I) signifient :
SGB : « Société G &amp; B African Resources Ltd » ; KPT : Kpétémé ; (A, B, C, D, E, F, G, H, I) : sommets du périmètre ainsi délimité.
