# Article 46
A défaut d'identification d'un revenu net déclaré, le travailleur de l'économie informelle opère un choix dans les catégories de revenus déterminés dans la grille annexée au présent arrêté.
Le montant du revenu net choisi sur la grille peut subir sur demande expresse de l'assuré, une réévaluation de 5 % maximum par an non cumulable d'une année sur l'autre.
