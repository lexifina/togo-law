# Article 64
Les deuxième et troisième examens médicaux prénataux sont obstétricaux. Ils sont effectués par un médecin ou une sage-femme et ont lieu : - le deuxième examen, vers le sixième mois de la grossesse ; - le troisième examen, vers le huitième mois de la grossesse ;
Les certificats correspondant à ces examens sont également établis sur papier libre.
