# Article 202
Les pièces à produire par les attributaires pour le compte des enfants à charge sont :
- les certificats d'assiduité pour les enfants placés en apprentissage, - les certificats d'inscription pour les enfants âgés de six (6) ans et plus, - les certificats médicaux pour les enfants de moins de six (6) ans et pour les enfants infirmes.
