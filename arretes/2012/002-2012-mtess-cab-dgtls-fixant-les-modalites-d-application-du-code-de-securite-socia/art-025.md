# Article 25
Les critères ci-après permettent de caractériser le travail dans le secteur informel :
1. la facilité d'accès aux activités ; - l'utilisation de ressources locales ; - la propriété familiale de l'activité ; - l'échelle restreinte des opérations ; - l'utilisation de techniques simples ; - des marchés échappant à toute réglementation et ouverts à la concurrence.
