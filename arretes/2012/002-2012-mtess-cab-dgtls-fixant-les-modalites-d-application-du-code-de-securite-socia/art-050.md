# Article 50
Toute action en poursuite, effectuée contre un employeur, un travailleur indépendant ou un travailleur de l'économie informelle qui ne s'exécute pas dans les délais légaux, est obligatoirement précédée d'une mise en demeure transmise avec accusé de réception l'invitant à régulariser sa situation dans les quinze (15) jours.
