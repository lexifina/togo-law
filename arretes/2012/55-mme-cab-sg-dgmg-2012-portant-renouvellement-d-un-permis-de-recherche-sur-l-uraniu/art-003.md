# Article 3
Les sommets de ce périmètre sont matérialisés sur le sol par des bornes en maçonnerie portant les inscriptions suivantes :
SGB-KPDA ; SGB-KPDB ; SGB-KPDC ; SGB-KPDD ; SGB-KPDE ; SGB-KPDF ; SGB-KPDG ; SGB-KPDH ; SGB-KPDI ; SGB-KPDJ ; SGB-KPDK ; SGB-KPDL.
Les inscriptions SGB, KPD et (A, B, C, D, E, F, G, H, I, J, K, L) signifient :
SGB : «Société G &amp; B African Resources Ltd» ; KPD : Kpédji (A, B, C, D, E, F, G, H, I, J, K, L) : sommets du périmètre ainsi délimité.
