# Article 2
— Les tarifs d'abatage pour les animaux abattus en supplément du permis de chasse sont fixés de la façon suivante et dans les limites autorisées :
| | MOYENNE CHASSE | CRANDE CHASSE | TARIF | | --- | --- | --- | --- | | Eléphants | 1 | 3 | 1.000 francs le 1er | | | | | 2.000 francs le 2e | | | | | 4.000 francs le 3e | | Hippopotames | 2 | 3 | 200 francs par tête | | Buffles | 6 | 10 | 100 francs par tête | | Hippotragues | 4 | 6 | 100 francs par tête |
