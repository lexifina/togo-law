# Article 3
— Les prix d'achat au producteur du beurre de karité brut sont fixés comme suit :
| Frs. | | | --- | --- | | Nuatja | 9.032 | | Atakpamé | 8.932 | | Blita | 8.768 | | Sokodé | 8.089 | | Kandé | 6.924 | | Mango | 6.172 | | Barkoissi | 5.935 | | Frs. | | | --- | --- | | Bogou | 5.840 | | Dapango | 5.605 | | Nadjondi | 5.372 |
Les prix dans les autres centres seront éventuellement fixés par les Chefs de Circonscription compte tenu des frais de transport routiers à raison de 7,90 la tonne kilométrique, ce tarif comportant le transport des fûts à la montée et la descente.
Les prix du beurre fondu et logé sont majorés de 1.264 frs. par tonne soit :
| Frais de fonte et manutention | 120 | | --- | --- | | Commission | 100 | | Déchets | 1.044 | | | 1.264 |
Cette somme reviendra aux S. I. P. lorsque celles-ci acheteront le beurre au producteur et le revendront fondu et logé au commerce.
