# Article 2
— Les prix aux producteurs des amandes de karité sont fixés comme suit :
| LOCALITÉS | PRIX aux producteurs | | --- | --- | | Nuatja | 2.397 | | Localités entre Awagomé et Blita inclus | 2.307 | | Bassari | 1.577 | | Guérin-Kouka | 1.287 | | Natchitikpi | 1.247 | | Nawaré | 1.337 | | Bapuré | 1.287 | | Kabou | 1.467 | | Sokodé | 1.877 | | Tchébébé | 2.227 | | Djabatauré | 2.127 | | Ayengré | 2.092 | | Tchamba | 1.702 | | Cambolé | 1.487 | | Bafilo | 1.572 | | Alédjo | 1.682 | | Lama-Kaza | 1.482 | | Aouandjello | 1.537 | | Sara Kaoua | 1.352 | | Aloum | 1.287 | | Niamtougou | 1.332 | | Siou | 1.287 |
Les prix dans les autres centres seront fixés par les Chefs de Circonscription compte tenu des frais de transport routiers calculés à raison de 5 francs la tonne kilométrique.
Les prix à payer aux intermédiaires seront ceux aux producteurs majorés de 65 francs; cette majoration reviendra aux S. I. P. lorsque l'achat au producteur et l'ensachage seront effectués par les S. I. P.
