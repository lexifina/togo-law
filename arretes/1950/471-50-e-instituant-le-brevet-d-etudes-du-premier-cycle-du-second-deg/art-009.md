# Article 9
— Chacune des épreuves est cotée de 0 à 20 et est affectée des coefficients suivants :
| Ecrit. | 0 | 1 | 2 | | --- | --- | --- | --- | | Français — Dictée | 1 | 3 | | | Composition | 2 | 3 | | | Mathématiques | 3 | | | | Langues vivantes | 2 | | | | Epreuve à option (1er Série) | 2 | | | | Oral. | 0 | 1 | 2 | | Lecture expliquée | 3 | | | | Histoire ou Géographie | 2 | | | | Epreuve à option (2e série) | 2 | | |
JOURNAL OFFICIEL DU TERRITOIRE DU TOGO
Aucun candidat ne peut être déclaré admissible aux épreuves de la 2e série s'il n'a pas obtenu la moyenne pour l'ensemble des épreuves de la 1re série. Le bénéfice de l'admissibilité n'est conservé que de la 1re à la 2e session de chaque année.
Sont déclarés définitivement admis les candidats qui ont obtenu la moyenne pour l'ensemble des épreuves de 1re et de 2e séries.
Aux différentes épreuves des deux séries, la note zéro est éliminatoire, si elle est maintenue après la délibération du Jury.
Aucun candidat ayant remis un livret scolaire ne pourra être éliminé soit à l'écrit soit à l'oral sans examen préalable de son livret.
