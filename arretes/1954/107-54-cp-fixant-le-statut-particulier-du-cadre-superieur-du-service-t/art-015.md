Le personnel du Corps des agents techniques est réparti en trois grades.
1° — Les agents techniques principaux; 2° — Les agents techniques de 1re classe; 3° — Les agents techniques de 2e classe.
Le grade d'agent technique principal comporte une classe exceptionnelle.
Le grade d'agent technique de 2e classe comprend quatre échelons.
Les grades d'agent technique de 1re classe et d'agent technique principal comprennent trois échelons.
La classe exceptionnelle d'agent technique principal comprend un seul échelon.
