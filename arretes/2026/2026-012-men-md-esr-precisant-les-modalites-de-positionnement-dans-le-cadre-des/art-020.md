# Article 20
Le test de positionnement est sanctionné par une attestation de positionnement qui précise :
➤ Pour les admis
- le niveau d'intégration dans le parcours ; - les unités de compétences validées ; - les modules d'appoint prescrits le cas échéant ; - les dispenses accordées le cas échéant ; - la durée estimative de formation - la décision du jury.
➤ Pour les ajournés
- les motifs de l'ajournement ; - les éventuels modules de préparation ; - la décision du jury.
L'attestation est signée par le président de jury de positionnement et remise au candidat.
