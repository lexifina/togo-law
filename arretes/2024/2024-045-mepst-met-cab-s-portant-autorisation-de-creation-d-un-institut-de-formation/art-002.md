# Article 2
La présente autorisation est accordée pour des formations modulaires dans les domaines suivants : CCNA (Cisco Certified Network Associate) ; CCNP ; CEH (Certified Ethical Hacker) ; NSE 4 (formation sur les parcs-feux fortigate) ; C1SSP (certification en sécurité de l'information) ; audit informatique ; gestion de projets (méthodologies et outils professionnels) ; Word avancé ; Excel avancé ; PowerPoint avancé ; développement d'applications mobiles ; développement plateformes Web.
