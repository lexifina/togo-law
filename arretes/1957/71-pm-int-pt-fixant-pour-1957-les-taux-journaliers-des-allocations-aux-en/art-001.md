| Vacances de Noël 1956-57. | 14.000 frs métro | | --- | --- | | Vacances de Pâques 1956-57. | 17.000 frs métro | | Grandes vacances (août-septembre) 50.000 frs métro | | | Assurance. | 450 frs métro | | Frais de blanchissage (10 mois). | 6.850 frs métro | | Dépôt de garantie scolaire. | 1.000 frs métro | | Total | 89.300 frs métro |
