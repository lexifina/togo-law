# Article 3
— Tableau de classement. Ne peuvent recevoir de gratification que les agents inscrits, sur la proposition de leur Chef de service, sur des tableaux de classement dressés pour l'exercice s'étendant du 1er janvier au 31 décembre. Ces tableaux sont établis avant le 31 décembre de chaque année.
Il est dressé un tableau pour le cadre supérieur et un tableau pour le cadre secondaire.
Dans les propositions de classement, les agents sont inscrits dans l'ordre décroissant ci-après :
Les agents proposés pour la majoration M¹, puis les agents proposés pour la majoration M³ et ainsi de suite pour les agents proposés pour les majorations M² et M¹, pour la gratification normale et, le cas échéant, pour chacune des gratifications réduites R¹, R² et R³.
A Valeur égale, la priorité est accordée; à l'agent qui est au grade le plus élevé; au même grade, à l'agent le plus ancien dans le grade; à égalité d'ancienneté, à l'agent le plus âgé.
Les agents non proposés pour une gratification, sont inscrits à la suite dans l'ordre de mérite décroissant.
Il n'est pas mentionné de notes chiffrées en regard des noms des agents inscrits.
