# Article 5
Les participants à STAR-UEMOA sont les structures suivantes :
- la BCEAO ; - les banques et établissements financiers agréés ; - les institutions financières régionales (BOAD, BIDC) ; - le DC/BR ; SICA-UEMOA ; le GIM-UEMOA ; - le SAGETIL-UMOA ; - les Trésors publics nationaux ; - les Sociétés de Gestion et d'intermédiation.
