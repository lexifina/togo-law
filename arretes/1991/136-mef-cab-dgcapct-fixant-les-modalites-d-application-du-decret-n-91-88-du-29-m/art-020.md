# Article 20
Pour obtenir le permis international de conduire le postulant doit fournir un dossier comprenant :
- une demande sur formulaire timbrée à 250 Fs. CFA ; - 3 photos (trois) d'identité ; - 2 timbres (deux) fiscaux de 250 F.CFA ; - une quittance attestant le paiement des droits afférents fixés conformément aux dispositions du code général des impôts.
