# Article 8
— L'action civile se prescrit selon les règles du Code Civil. Toutefois, cette action ne peut plus être engagée devant la juridiction répressive après l'expiration du délai de prescription de l'action publique.
Lorsqu'il a été définitivement sur l'action et si une condamnation pénale a été prononcée, l'action civile mise en mouvement dans les délais prévus par l'article précédent obéit aux règles du Code Civil et du code de Procédure Civile.
