# Loi, Article 3
— Dans la mesure où les délais de citation, de recours ou de notifications déterminés par le Code de Procédure Pénale sont plus courts que ceux déterminés par les textes antérieurs, les parties intéressées pourront signifier leurs actes selon les délais antérieurs dans tous les cas où ces délais ne se trouveraient pas expirés à la date de publication du Code de Procédure Pénale.
