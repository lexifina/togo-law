# Article 143
Les aéronefs utilisés par les entreprises togolaises de transport public doivent être immatriculés au Togo.
Le ministère chargé de l'aviation civile peut cependant autoriser une entreprise à utiliser temporairement un aéronef immatriculé à l'étranger. L'autorisation sera accordée pour une durée maximum de six mois, elle est renouvelable.
