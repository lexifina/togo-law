# Article 619
Les carrières sont classées en deux (02) catégories :
1- les carrières permanentes ouvertes, soit sur le domaine de l'Etat soit sur un terrain de propriété privée bénéficiant d'une autorisation réglementaire d'ouverture et d'exploitation ;
2- les carrières temporaires ouvertes soit sur le domaine de l'Etat soit sur un terrain de propriété privée dont l'exploitation est soumise aux mêmes conditions qu'à l'alinéa précédent.
