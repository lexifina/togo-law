# Article 475
Si l'enclave résulte de la division d'un fonds par suite d'une convention, le passage ne peut être demandé, dans les trente (30) ans suivant la division, que sur les terrains qui sont issus de cette division.
Toutefois, le propriétaire du fonds enclavé peut, dans le cas où aucun passage suffisant ne pourrait être établi sur les fonds divisés, intenter l'action prévue à l'article 473 du présent code.
