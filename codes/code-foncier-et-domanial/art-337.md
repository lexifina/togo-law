# Article 337
Le juge saisi peut ordonner la démolition de l'ouvrage public érigé en violation du droit de propriété lorsqu'aucune régularisation appropriée n'est possible ou lorsque les inconvénients de son implantation irrégulière l'emportent sur les avantages pour l'intérêt général à le maintenir en l'état.
Lorsqu'une régularisation appropriée est possible, l'administration doit engager une nouvelle procédure d'expropriation pour cause d'utilité publique.
