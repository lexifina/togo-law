# Article 606
Toute exploitation ou installation relative à l'utilisation des ressources en eau dans un but d'intérêt général grève les fonds de terre intermédiaires d'une servitude de passage, notamment pour les lignes électriques, les chemins de fers, les chemins d'accès, les conduites souterraines, les canaux d'amenee d'eau aux usines, les canaux d'irrigation et de drainage.
