# Article 398
L'occupation temporaire prévue par les articles 392 à 397 du présent code ne peut être autorisée pour une période supérieure à cinq (05) années.
Si l'occupation se prolonge au-delà de cette période et à défaut d'accord, l'administration doit procéder à l'expropriation dans les formes prévues par le présent code.
