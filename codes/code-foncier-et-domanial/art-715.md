# Article 715
Tous les faits et conventions, ayant porté sur un immeuble immatriculé ou non, ayant eu pour effet de constituer, transmettre, déclarer, modifier ou éteindre un droit réel immobilier, intervenus avant la date de prise d'effet du présent code sont valables.
Toutefois, les titulaires de ces différents droits disposent d'un délai de cinq (05) ans pour se conformer aux prescriptions du présent code.
Passé ce délai, les dispositions des articles 281 et 282 du présent code sont appliquées.
