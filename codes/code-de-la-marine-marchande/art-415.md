# Article 415
Lorsque, aucun État ne reconnaît le passager clandestin comme étant son ressortissant, l'administration maritime autorise le renvoi du passager clandestin dans l'État dans lequel se trouve le port qu'elle estime être son port d'embarquement.
En cas de doute sur le port d'embarquement, l'administration maritime peut autoriser le renvoi du clandestin dans l'État dans lequel se trouve le dernier port d'escale avant qu'il ait été découvert.
Enfin, lorsqu'un passager clandestin ne peut être renvoyé conformément aux paragraphes 1 et 2, l'administration maritime peut autoriser son renvoi dans l'État dont le navire bat pavillon quand le passager clandestin fut découvert.
