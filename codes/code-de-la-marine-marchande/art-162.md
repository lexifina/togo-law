# Article 162
Les différentes visites auxquelles sont astreints les navires sont :
- la visite avant la mise en service ;
- les visites annuelles ;
- les visites périodiques ;
- les visites de partance ; - les visites sur réclamation d'équipage ; - les visites exceptionnelles ; - les visites occasionnelles ; - les visites inopinées ; - les visites de sûreté ; - les visites sur réquisition de l'administration maritime.
