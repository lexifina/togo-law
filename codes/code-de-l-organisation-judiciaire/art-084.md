# Article 84
Le président du tribunal de grande instance ou le juge du siège désigné par lui à cet effet, est compétent pour :
- statuer sur les procédures de référé ; - rendre les ordonnances sur requête ; - connaître du contentieux de l'exécution des décisions du tribunal de grande instance ;
- connaître des demandes d'exéquatur ; - organiser et répartir les tâches juridictionnelles entre les membres du tribunal au vu des conclusions des réunions ; - nommer les présidents de chambres ; - administrer le tribunal.
Le président du tribunal de grande instance peut présider l'une des chambres, lorsque les circonstances l'exigent.
