# Article 74
Dans les tribunaux de grande instance, les magistrats momentanément empêchés sont suppléés : - le président par le vice-président ; - le vice-président par le juge le plus ancien dans le grade le plus élevé ; - le procureur de la République par le substitut le plus ancien dans le grade le plus élevé ; - les juges d'instruction, les juges des enfants et les juges de l'application des peines se suppléent entre eux. A défaut, le président du tribunal assure la fonction ou y délègue un magistrat du siège.
