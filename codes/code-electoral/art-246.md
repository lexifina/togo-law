# Article 246
Tout conseiller municipal, qui, pour une cause quelconque, se trouve dans l'un des cas d'inéligibilité prévus par la loi, peut-être, à tout moment, déclaré démissionnaire par l'autorité de tutelle. Le conseiller déclaré démissionnaire peut exercer un recours devant le Conseil d'Etat dans un délai de dix (10) jours suivant la notification.
