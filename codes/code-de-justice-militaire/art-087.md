# Article 87
Le procureur militaire est chargé de poursuivre les prévenus et inculpés renvoyés devant le tribunal militaire.
A cet effet, il fait citer devant le tribunal militaire, notamment le prévenu ou l'inculpé, la partie civile, les témoins et, le cas échéant, le civilement responsable et les appelés en garantie.
