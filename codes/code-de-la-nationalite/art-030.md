# Article 30
Toute déclaration en vue d'acquérir, de décliner ou de répudier la nationalité togolaise, dans les cas prévus par le présent code est souscrite devant le
Président du tribunal de droit moderne de première instance ou devant le juge de section dans le ressort duquel le déclarant a sa résidence.
Lorsque le déclarant se trouve hors du Togo, la déclaration est souscrite devant les agents consulaires représentant la République Togolaise.
