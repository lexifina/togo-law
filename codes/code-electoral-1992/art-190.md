# Article 190
Le Conseil de Préfecture se compose de :
— 15 membres pour les préfectures dont la population est comprise entre 0 et 100 000 habitants ;
— 21 membres pour les préfectures dont la population est comprise entre 100 000 et 200 000 habitants ;
— 31 membres pour les préfectures dont la population est égale ou supérieure à 200 000 habitants.
