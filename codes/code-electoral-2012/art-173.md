# Article 173
Sont inéligibles les individus condamnés lorsque leur condamnation empêche d'une manière définitive leur inscription sur une liste électorale.
Les individus dont la condamnation empêche temporairement l'inscription sur la liste électorale sont inéligibles pendant la période durant laquelle ils ne peuvent être inscrits sur la liste électorale.
Sont également inéligibles :
- les individus privés par décision judiciaire de leur droit d'éligibilité en application des lois en vigueur ; - les incapables majeurs.
