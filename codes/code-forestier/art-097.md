# Article 97
Les agents assermentés de l'Administration des ressources forestières, revêtus de leur uniforme ou munis de signes distinctifs de leurs fonctions, peuvent se transporter sur tous les lieux pour constater les infractions et rassembler les preuves.
Les visites domiciliaires, les perquisitions ou les inspections doivent se faire conformément aux dispositions du code de procédure pénale.
