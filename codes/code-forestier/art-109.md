# Article 109
L'Administration des ressources forestières peut interjeter appel des jugements rendus en première instance et user des voies de recours prévues par le code de procédure pénale. L'action publique en matière d'infraction au présent code se prescrit en :
- dix ans en matière de crime ; - cinq ans en matière de délit ; - un an en matière de contravention.
