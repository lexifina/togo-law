# Article 93
Les agents de l'Administration des ressources forestières opèrent sur l'étendue du territoire dans :
- les domaines forestiers de l'État ; - le domaine foncier national portant les formations boisées naturelles ou artificielles ;
- tout lieu public portant des boisements et plantations conservés ou réalisés dans un but de protection, d'ornement ou d'amélioration de l'environnement ; - les propriétés privées plantées d'espèces forestières, dans les cas prévus par les règlements.
