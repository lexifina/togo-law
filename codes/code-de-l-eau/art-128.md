# Article 128
Une action en affranchissement des droits d'usage peut, dans tous les cas, être intentée devant les tribunaux par les propriétaires de terrains compris dans le périmètre améliore. Dans le cas où l'exécution des travaux de dessechement a porté atteinte à l'exercice des droits d'usage, l'action peut également être intentée par les usagers lésés.
