# Article 80
Les témoins défaillants encourent une amende qui ne peut excéder trois mille (3000) francs CFA prononcée par le juge enquêteur. Ils sont reconvoqués à leurs frais.
Si les témoins reconvoqués sont encore défaillants, le juge peut les condamner à une nouvelle amende n'excédant pas quinze mille (15000) francs CFA et il peut décerner contre eux mandat d'amener dans les formes prévues au code de procédure pénale.
