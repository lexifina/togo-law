# Article 86
Le matériel électoral par bureau de vote comprend notamment :
- une urne transparente sur un côté au moins avec deux (2) cadenas ; - un ou plusieurs isoloirs ; - deux (2) lampes tempêtes ; - l'encre indélébile ; - le cachet “A voté” ; - l'encreur ; - la liste électorale du bureau de vote ; - la liste d'emargement ; - le procès-verbal en plusieurs exemplaires ; - les fiches de dépouillement ; - le bulletin unique de vote.
