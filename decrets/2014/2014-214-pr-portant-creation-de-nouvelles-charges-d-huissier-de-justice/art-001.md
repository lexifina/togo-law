# Article 1
Il est créé des charges d'huissiers de justice dans les ressorts des juridictions de première instance ci-après :
- Tribunal de première instance de Lomé : charge n° 101 ; - Tribunal de première instance de Bassar : charge n° 02 ; - Tribunal de première instance de Pagouda : charge n° 01 ; - Tribunal de première instance d'Elavagnon : charge n° 01 ; - Tribunal de première instance de Dapaong : charge n° 03.
