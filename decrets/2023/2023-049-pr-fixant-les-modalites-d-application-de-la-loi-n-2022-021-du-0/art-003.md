# Article 3
Peuvent bénéficier du statut de zone franche industrielle dans le secteur du textile et de l'habillement, les entreprises du secteur qui entrent dans une ou plusieurs des catégories ci-après :
- les entreprises à forte intensité de main d'œuvre nationale ;
- les entreprises axées sur l'utilisation des matières premières locales ; - les entreprises pratiquant la sous-traitance internationale ; - les entreprises produisant les intrants pour les entreprises énumérées ci-dessus.
