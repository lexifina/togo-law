# Article 7
Les critères visés à l'article précédent ont pour objectif d'inciter les communes à améliorer leur performance.
La dotation de performance est répartie par commune, selon les critères de performance, comme suit :
| Critère | Taux supérieur à 50 % | Taux inférieur ou égal à 50 % | | --- | --- | --- | | Taux d'utilisation des dotations du FACT | 0,4 % | 0% | | Taux d'exécution du budget local (capacité de mobilisation des ressources propres) | 0,4% | 0 % | | Critère | | OUI | NON | | --- | --- | --- | --- | | Respect du nombre de sessions ordinaires annuels | | 0,4 % | 0% | | Respect du délai d'adoption du budget primitif | | 0,4% | 0 % | | PDC | Son élaboration | 0,2 % | 0 % | | | Son approbation | 0,2 % | 0 % |
