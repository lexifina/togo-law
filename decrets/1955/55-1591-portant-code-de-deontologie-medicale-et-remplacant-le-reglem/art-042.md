# Article 42
Le forfait pour la durée d'un traitement est interdit, si ce n'est pour un accouchement, une opération chirurgicale, un traitement physiothérapeutique, un traitement dans une station de cure ou un établissement de soins, ou dans quelques cas exceptionnels pour une série d'interventions, après accord du conseil départemental.
Le forfait pour l'efficacité d'un traitement est interdit en toutes circonstances.
