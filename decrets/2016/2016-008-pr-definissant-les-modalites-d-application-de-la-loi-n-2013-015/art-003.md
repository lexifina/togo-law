# Article 3
Le chef de file de l'opposition est le premier responsable du parti ayant obtenu le plus grand nombre de députés aux dernières élections législatives. Lorsque plusieurs groupes forment l'opposition, c'est le chef du groupe numériquement le plus important de l'opposition qui a la qualité de chef de file de l'opposition.
Le chef de file de l'opposition n'est pas nécessairement membre du parlement.
