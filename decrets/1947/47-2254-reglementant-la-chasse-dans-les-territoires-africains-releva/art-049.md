# Article 49
— Les peines encourues d'amende ou de prison sont portées au double obligatoirement :
1° Lorsque le délit a été commis dans une réserve naturelle intégrale, parc national, réserve de faune;
2° Dans le cas de récidive, réalisé lorsque dans les cinq années qui ont précédé l'infraction le délinquant a déjà été condamné pour une infraction prévue au présent décret.
