# Article 92
— Dans chaque exploitation dont l'effectif moyen dépasse 100 personnes, une visite des travailleurs se déclarant malades est passée chaque matin avant le début du travail. Les femmes et les enfants des travailleurs de l'exploitation, s'ils le demandent, peuvent se présenter à cette visite pour y être examinés et, le cas échéant, recevoir les soins et les traitements nécessaires.
Les résultats de cette visite sont consignés sur un registre spécial dont le modèle est fixé par arrêté du chef du territoire.
