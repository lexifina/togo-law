# Article 3
— Le travailleur ne peut engager ses services qu'à temps ou pour un ouvrage déterminé.
Pour les travailleurs originaires du territoire, lorsque le contrat est conclu pour une durée déterminée, celle-ci ne peut excéder deux ans et un an lorsqu'ils sont mariés et que leur famille ne les accompagne pas sur les lieux du travail.
