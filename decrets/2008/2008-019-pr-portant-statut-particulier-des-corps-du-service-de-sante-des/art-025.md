# Article 25
Pour être promus au grade supérieur, les pharmaciens chimistes des armées doivent compter au minimum :
- quatre (4) ans dans le grade de pharmacien chimiste lieutenant ; - cinq (5) ans dans le grade de pharmacien chimiste capitaine ; - cinq (5) ans dans le grade de pharmacien chimiste commandant ; - cinq (5) ans dans le grade de pharmacien chimiste lieutenant-colonel ; - quatre (4) ans dans le grade de pharmacien chimiste colonel.
