# Article 17
La limite d'âge dans les différents corps d'officiers de l'armée de l'air est établie comme suit :
| - sous-lieutenant et lieutenant | 54 ans ; | | --- | --- | | - capitaine | 55 ans ; | | - commandant | 56 ans ; | | - lieutenant-colonel | 58 ans ; | | - colonel | 59 ans ; | | - général | 60 ans . |
