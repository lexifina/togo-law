# Article 3
Les commissaires constituent un corps d'officiers dont la hiérarchie comporte les grades suivants :
1°) Officiers subalternes : - commissaire sous-lieutenant ; - commissaire lieutenant ; - commissaire capitale.
2°) Officiers supérieurs : - commissaire commandant ; - commissaire lieutenant-colonel ; - commissaire colonel.
3°) Officiers généraux : - commissaire général de brigade ; - commissaire général de division.
Les commissaires généraux de division peuvent recevoir rang et appellation de commissaire général de corps d'armée et de commissaire général d'armée.
