# Article 22
Les limites d'âge des officiers de la marine sont les suivantes :
| - enseignes de vaisseau | 54 ans ; | | --- | --- | | - lieutenant de vaisseau | 55 ans ; | | - capitaine de corvette | 56 ans ; | | - capitaine de frégate | 58 ans ; | | - capitaine de vaisseau | 59 ans ; | | - amiral | 60 ans . |
