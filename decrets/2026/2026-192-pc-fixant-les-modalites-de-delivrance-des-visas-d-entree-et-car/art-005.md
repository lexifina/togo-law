# Article 5
Les visas d'entrée au Togo comprennent les visas de court séjour, les visas de long séjour et le visa de courtoisie.
• Les visas de court séjour :
- le visa de transit ; - le visa touristique ; - le visa religieux ; - le visa médical ; - le visa de service ; - le visa d'affaires courte durée.
• Les visas de long séjour :
- le visa de travail ; - le visa d'affaires longue durée ; - le visa d'études ou de stage ; - le visa familial.
• Le visa de courtoisie.
