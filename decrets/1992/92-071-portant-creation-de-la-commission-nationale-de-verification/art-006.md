# Article 6
Les commissions régionales de constatation comprennent dans chaque région économique : - Deux membres de la commission nationale ; - Les préfets ; - Les chefs de cantons ; - Les présidents des tribunaux de première instance ; - Les commandants de brigades de gendarmerie ; - Les responsables des affaires sociales ; - Les présidents des conseils de préfectures ; - Le directeur régional de l'environnement ; - Le directeur régional du plan ; - Les représentants des collectivités contestatrices ; - Le directeur régional du développement rural ; (un représentant par collectivité) ; - Les représentants des organisations non gouvernementales présentes dans la région.
