# Article 3
Le système national d'aires protégées comprend sept catégories qui sont :
- les réserves naturelles intégrales ou scientifiques ; - les parcs nationaux ; - les monuments naturels ; - les réserves de gestion des habitats ou des espèces ; - les paysages protégés ; - les zones de nature sauvage ; - les zones protégées de gestion de ressources naturelles.
Des objectifs spécifiques de gestion sont assignés à chaque catégorie d'aire protégée.
