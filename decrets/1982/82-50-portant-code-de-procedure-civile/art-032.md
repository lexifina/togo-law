# Article 32
Les fins de non recevoir doivent être relevées d'office lorsqu'elles ont un caractère d'ordre public, notamment lorsqu'elles résultent de l'inobservation des délais dans lesquels doivent être exercées les voies de recours.
Le juge peut recevoir d'office la fin de non recevoir tirée du défaut d'intérêt.
